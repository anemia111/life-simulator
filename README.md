# Life Simulator — Phase 4 / v0.5.0

**[ブラウザでプレイする](https://anemia111.github.io/life-simulator/)** · [ソース](https://github.com/anemia111/life-simulator)

PC・スマホで、働き、学び、暮らしを組み立てる人生・経済シミュレーション。勝利条件も寿命による終了もありません。React / TypeScript / Vite / Tailwind CSS / Zustand / IndexedDBを使用しています。

## Phase 4：街の自律シミュレーション

「世界・都市経済」で都市指標、競合企業、NPC、労働市場、市場シェア、実イベントのニュースを確認できます。32人の重要NPCと開始時20社を個別に処理し、一般住民は6地区の集計モデルで更新します。

- NPCは資金・能力・求人・通勤・生活費を比較して就職・転職・学習・消費・貯蓄・住み替え・小商いを選択
- 企業は自分の資金で給与、仕入、管理、広告、設備、借入、出店・撤退を処理
- プレイヤーとAI企業に業界別の有限需要を配分。売上は配分・価格・供給・資金に因果的に連動
- 求人枠をNPCと共有し、プレイヤー事業のスタッフも実際の求職者から採用
- 月次で地域の人口・所得・賃金・家賃相場・地価・失業・需要・物価・景気・金利を更新
- マップの競合入居・空室と実企業を一致させ、人口・地価・需要・求人の表示を切替
- 保存v5、v1〜v4引継ぎ。10年間3,653日の不変条件と保存後の継続再現性を自動検証

詳しい数式と追加契約は [WORLD_SYSTEM.md](WORLD_SYSTEM.md)、実装範囲は [PHASE4_DESIGN.md](PHASE4_DESIGN.md)。AIの業界生産は集計モデル、プレイヤー事業の在庫・契約・月額課金は詳細モデルです。完全な閉鎖経済、家族、共同創業交渉、多都市、M&Aは未実装です。

## 最初の遊び方

1. 人生を開始し、「仕事を探す」でカフェなどに応募。応募は1時間を使います。
2. 1/7/30日を進めるとシフトどおりに自動勤務し、実務経験と給与債権が発生します。給与は契約の25日/28日に銀行へ入金されます。
3. 「行動メニュー」で平日・土日の学習・休息・交流・事業と時間を設定します。設定を毎日繰り返す必要はありません。
4. 経験を積んだら夕方のコンビニなどへ応募し、掛け持ち。「仕事・シフト管理」で曜日・開始時刻、欠勤、退職を管理できます。
5. 「暮らし」で節約・住居・睡眠を調整し、「資産と収支」で現金と預金、月次報告を見ながら貯めます。
6. 職場で知り合った人とは「人間関係」で交流。自動交流を使う場合は相手を選び、行動方針も交流へ設定します。
7. 「事業を営む」で名前・業種・地域・資金・設備・価格・方針を選んで開設。小売なら「商品・サービス」で在庫を仕入れます。
8. 「余暇の予定を事業運営にする」で作業を自動化。複数事業には「設備・運営」の作業比率で時間を分配します。学習や休養と平日・休日で組み合わせられます。
9. 「事業別財務」で売上・利益・現金を確認し、設備・品質・広告・人材などに再投資。個人事業の余剰現金は本人の預金に回収できます。
10. 「会社・所有権」で設立費1万円＋資本金1万円以上を用意して会社を設立。新しい法人事業を開くか、単独所有会社へ個人事業を移管できます。
11. 法人事業の回収先は会社口座です。個人への報酬は役員報酬または利益の範囲で配当。会社の現金を生活費へ直接使うことはできません。
12. 休止・閉鎖後も未払い・返品義務・売掛金は残り、資金補填と清算が可能。仕事だけの人生も、複数会社の経営も自由です。

家賃1日、光熱費10日、通信費15日、食費等は毎日、交通費は出勤日に発生します。不足分は未払いになり、入金時に自動返済されます。借入は残高10万円まで、月初の利息1%。借入は任意返済です。年齢や赤字による強制終了はありません。

## 都市マップの遊び方

1. 「都市マップ」で地区→地点を選択。PCは左に地図・右に詳細、スマホは物件の詳細パネルを開きます。「地図に戻る」で閉じられます。
2. 住居は月額賃料と職場までの通勤を比較して引越し。地区変更は5,000円＋当月家賃の増額差額、手続き2時間。通勤で睡眠・シフトと重複する場合は拒否し、先に勤務予定を調整します。
3. 青い勤務先から応募できます。求人画面でも地区名・交通費・現在の自宅からの通勤時間を比較できます。地区データから生成した6求人を既存8求人に追加しています。
4. 事業を開設して事業口座に資金を用意し、空き店舗・オフィス・倉庫を契約。契約時に当月賃料、以後毎月1日に請求します。法人は法人財務から支払います。
5. 「基準条件での需要」で現在の事業と候補物件を比較。実売は作業時間・在庫・資金でさらに制限されます。在宅運営は引き続き可能です。
6. 本人は最初の賃貸拠点へ往復します。移動後に0.5時間以上の作業を確保できない割当は休息に戻します。従業員は有償の実働を別に供給します。
7. 図書室や公園を日常施設に登録すると「あなたの生活圏」から選べます。利用は手動で、滞在1時間＋往復移動と利用料・交通費を消費します。

## セーブの互換性

公開サイトで以前のセーブを選ぶとv4へ移行します。旧JSONも取り込めます。現金・債務・未払給与・事業・設備・能力・日付を保持します。旧版に記録がなかった勤務時間は勤務日数から推定し、旧日次の時間配分等は未記録と表示します。移行前の月次集計は保存されていた記録の範囲です。

セーブは同じ端末・ブラウザ・接続先URLに保存されます。GitHubやサーバーには送信しません。端末を移す際はJSONを書き出して取り込んでください。サイトデータ消去に備えてバックアップを推奨します。複数タブの同時編集では最後の保存が優先されます。

## 未実装・簡略化

1都市・6地区、固定人口・安定した景況を基礎にしたモデルです。企業の基礎収入と支出、求人・人物・市場は簡略化しています。勤務曜日と開始時刻は自由に変更でき、企業別の交渉制約はまだありません。

公開株式市場・M&A・評価交渉、共同創業、不動産売買、税・社会保険、減価償却、NPCの独立した人生・NPC同士の交流、家族、複数都市、クラウド同期は未実装です。役割昇格はレベルとして記録し、詳細な職務権限は次の拡張対象です。

日次の計算順序は睡眠→勤務→余暇です。時間配分と実働は管理しますが、分刻みのイベント順序や現実の労働・金融制度を完全には再現していません。

Phase 2の簡略化：ソフトウェアは30日周期の後払い（月額期間終了時の売上認識）。休止・保守費不足時は顧客を失い未請求分を放棄。従業員は有償の固定シフトで、給与交渉・育成・独立した転職AIは未実装。店長や役員への完全委任は今後で、今回は管理担当による管理時間削減が動作します。会社は実在の法制度を再現せず、税・登記・破産手続を簡略化しています。旧2業種の法人移管は対象外です。

記録は日次365日・月次所有者別240件・元帳2000件（古い元帳はチェックポイント化）。現在残高と累積値は継続します。JSON取込は従来の8MB制限を維持しており、多数事業の大規模データの分割保存は将来対応です。

Phase 3の制限：経路は直線距離と平均速度による概算で、0.5時間単位に切上げます。契約交通費は既存の基準額に距離差を反映し、一般施設の移動運賃とは別の簡略モデルです。複数勤務先は各々自宅往復、複数事業物件の本人移動先は最初の拠点。商品・ソフトウェア顧客は集約モデルで、競合施設の独立した在庫や人流AIは未実装です。

複数都市への移住、鉄道・道路網による経路探索、地価変動・再開発・時間帯別人流・物流網、不動産購入・所有・転貸・敷金・契約更新交渉は未実装です。購入価格は参考情報として表示します。事業の休業中も賃料が発生し、解約月の返金はありません。
