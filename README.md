# Life Simulator — v0.6 / Phase 5

**[ブラウザでプレイする](https://anemia111.github.io/life-simulator/)** · [GitHubリポジトリ](https://github.com/anemia111/life-simulator)

一人の人生から始まる、自由な生活・仕事・経済シミュレーション。勝利条件、強制的な起業ルート、寿命や資金不足による終了はありません。React / TypeScript / Vite / Tailwind CSS / Zustand / IndexedDBを使用し、計算はUIから独立しています。

## v0.6で追加したこと

「人生・目標」の4タブから、自由な目標、人物ごとの人生年表、双方向の交流・交際、家族と共同資金を操作できます。

- 目標レジストリ：備え、仕事、友人、技能、事業、家族。進捗・達成・休止・再開。プレイヤーへの強制目標なし。
- NPCの価値観・関心・長期目標・ストレス・リスク許容。学習目標が学ぶ技能を、失敗の記憶が次の起業に必要な備えを変える。
- NPC同士の週次交流。実際の時間、相手の予定、交通費、手元資金、職場・近隣の接点を使用。
- 双方の親密度と信頼から友情・親友・交際・結婚が成立。成人、希望、親族、既存の交際相手、交際期間を確認。交際終了も可能。
- 実際の就退職、創業・撤退、転居、友情、交際、結婚、子ども、誕生日、目標達成を年表へ記録。直近24件の記憶と重要な年表を分離。
- 結婚後の同居、子どもの迎え入れ、NPC家族の住み替え・出生。養育は毎日0.5時間/子を分担し、勤務・生活・勉強と同じ24hへ計上。
- 独立した世帯帳簿。個人からの積立、月次自動積立、持分の返還、共同家賃・光熱・通信・子どもの日用品、資金不足時の未払い。個人・会社・世帯のお金を混同しない。
- 保存v6。v1〜v5の実fixtureを維持し、個人資金・事業・勤務・地図を引継ぐ。

ゲーム向けの関係・家族・費用モデルです。現実の婚姻、養育、医療、法律制度を正確に再現するものではありません。設計は [SOCIAL_SYSTEM.md](SOCIAL_SYSTEM.md)、着手時の監査は [PHASE5_DESIGN.md](PHASE5_DESIGN.md)。

## 規模と現在地

標準の開始条件は青葉市1都市、6地区、集計人口12万人、個別NPC32人、AI企業20社です。v0.6でファミリー住居6件を追加し、マップは74地点（住居24、事業18、勤務14、競合6、施設12）になりました。人口・企業数は時間で変化し、NPCの出生は個別人物と地区人口の両方へ反映します。

世界人口80億人や世界企業2,000〜3,000社は**将来仕様であり未実装**です。500人を個別化した30日間の負荷テストは標準プリセットと分けて実行します。これを現実規模の経済の検証済みと解釈しないでください。背景住民の経済は集計モデル、重要NPCは個別、AIの業界供給は集計、プレイヤーの在庫・案件は詳細モデルです。

## 最初の遊び方

1. 名前と初期条件を選び、仕事を探す画面でカフェなどへ応募します。
2. 1/7/30日を進めると自動勤務。給与債権が発生し、契約の給与日に銀行へ入金されます。
3. 行動メニューで平日・休日の学習・休息・事業などを設定し、暮らしで生活水準を調整します。
4. 人生・目標で自由に目標を選びます。知人とは職場で出会うほか、交流・交際タブから会いに行けます。相手が忙しい日は別の日を選んでください。
5. 資金と技能を使い、小売・制作・ソフトウェアなどの小さな事業を始め、利益を再投資できます。
6. 親しくなった相手と交際し、90日以上続けて互いの意思と条件が整えば結婚できます。結婚の準備費は5,000円です。
7. 共同資金への積立を設定し、家族に合う住居へ引っ越します。養育を始めるには双方20歳以上、十分な広さ、6万円の備えと時間が必要です。迎え入れの準備費は15,000円。家族を作ることも必須ではありません。

## 開発・検証

Node.js 24系を使用しています。

```sh
npm ci
npm run dev
npm test
npx playwright install chromium
npm run test:e2e
npm run build
```

`build`はTypeScriptの型チェックを含みます。検証結果・長期進行・実画面は [VERIFICATION.md](VERIFICATION.md) に記録します。mainへpushすると [Pagesワークフロー](.github/workflows/pages.yml) が計算・ブラウザ・ビルドを検証し、成功後にGitHub Pagesへ公開します。Viteは相対アセットパスに対応します。

## 拡張と未実装

[MASTER_DEVELOPMENT.md](MASTER_DEVELOPMENT.md) が統合要求、[ROADMAP.md](ROADMAP.md) が段階別の完成範囲です。[ARCHITECTURE.md](ARCHITECTURE.md)、[GAME_DESIGN.md](GAME_DESIGN.md)、[WORLD_SYSTEM.md](WORLD_SYSTEM.md)、[SOCIAL_SYSTEM.md](SOCIAL_SYSTEM.md)、[INDUSTRY_MODULES.md](INDUSTRY_MODULES.md)、[TEST_PLAN.md](TEST_PLAN.md)、[AGENTS.md](AGENTS.md) を参照してください。

新しい生活行動はActionDefinition、目標はGoalDefinition、業界はIndustryModuleとWorldIndustryModelへ登録します。事業・会社数のゲーム上の固定上限を設けず、資金・時間・需要・設備・管理費で制約します。

公開株式市場・取引所・指値注文・世界企業200〜500社、指数・ファンド・IPOは次のv0.7。世界企業2,000〜3,000社、架空国家・通貨・為替はv0.8。学校・資格・医療・税・社会保障・所有不動産・銀行・詳しい家族制度はv0.9。複数都市・M&Aなどの統合はv1.0です。

v0.6の家族は同居・婚姻・子ども・共通家計の基本です。離婚・財産分与・再婚世帯の再編・相続・学校・妊娠出産医療は未実装。NPCの住宅は代表地点による住居モデルで、全住戸の供給と個別占有は未実装です。移動は概算の距離から0.5h単位で計上し、分刻みの順序は扱いません。世界経済は外部部門を含む開放モデルで、一般人口の完全な家計・税・銀行決済の閉鎖会計ではありません。

個人元帳5,000件、事業元帳2,000件、NPC/AI/世帯元帳60件はチェックポイント付きで圧縮し、累積残高を保持します。人生年表は重要な節目を保持します。JSON取込16MB、IndexedDBはブラウザ容量に依存。大規模な分割保存、Web Workerによる処理分離、別タブ間の編集ロック、クラウド同期は未実装です。
