# Life Simulator — Phase 1 / v0.2.0

**[ブラウザでプレイする](https://anemia111.github.io/life-simulator/)** · [ソース](https://github.com/anemia111/life-simulator)

PC・スマホで、働き、学び、暮らしを組み立てる人生・経済シミュレーション。勝利条件も寿命による終了もありません。React / TypeScript / Vite / Tailwind CSS / Zustand / IndexedDBを使用しています。

## 今回できること

- 24時間の生活予算：睡眠・食事・勤務・通勤・学習・交流・事業・自由時間
- 都市の8求人を比較し応募、採用・不採用、最大4件の掛け持ち
- 契約別の曜日と開始時刻を管理。通勤を含む重複を防止
- 経験・技能・評価・昇給・役割昇格、欠勤と退職・転職、職務経歴
- 住居・生活水準・買い物、疲労・睡眠不足・健康・満足度
- 職場の人物と知り合い、交流で信頼を育てる
- 現金・預金・未払給与・資産・債務の区別、口座振替・借入・返済
- カレンダー、24h配分、日次・月次の収支と実績
- 従来の文章制作・焼き菓子事業、価格調整・設備再投資・休廃業
- IndexedDB 3枠、JSON入出力、v0.1セーブの自動移行

## 最初の遊び方

1. 人生を開始し、「仕事を探す」でカフェなどに応募。応募は1時間を使います。
2. 1/7/30日を進めるとシフトどおりに自動勤務し、実務経験と給与債権が発生します。給与は契約の25日/28日に銀行へ入金されます。
3. 「行動メニュー」で平日・土日の学習・休息・交流・事業と時間を設定します。設定を毎日繰り返す必要はありません。
4. 経験を積んだら夕方のコンビニなどへ応募し、掛け持ち。「仕事・シフト管理」で曜日・開始時刻、欠勤、退職を管理できます。
5. 「暮らし」で節約・住居・睡眠を調整し、「資産と収支」で現金と預金、月次報告を見ながら貯めます。
6. 職場で知り合った人とは「人間関係」で交流。自動交流を使う場合は相手を選び、行動方針も交流へ設定します。
7. 資金が貯まったら個人事業を開業。余暇の範囲で運営し、仕事と両立できます。

家賃1日、光熱費10日、通信費15日、食費等は毎日、交通費は出勤日に発生します。不足分は未払いになり、入金時に自動返済されます。借入は残高10万円まで、月初の利息1%。借入は任意返済です。年齢や赤字による強制終了はありません。

## セーブの互換性

公開サイトで以前のセーブを選ぶとv2へ移行します。旧JSONも取り込めます。現金・債務・未払給与・事業・設備・能力・日付を保持します。旧版に記録がなかった勤務時間は勤務日数から推定し、旧日次の時間配分等は未記録と表示します。移行前の月次集計は保存されていた記録の範囲です。

セーブは同じ端末・ブラウザ・接続先URLに保存されます。GitHubやサーバーには送信しません。端末を移す際はJSONを書き出して取り込んでください。サイトデータ消去に備えてバックアップを推奨します。複数タブの同時編集では最後の保存が優先されます。

## ローカルで起動

Node.js 24以降。Windowsでは `START_GAME.cmd` をダブルクリックします。

```powershell
npm ci
npm run dev
```

既定URLは http://localhost:5173/ 。スマホの実機では同一LANからターミナルに表示されるNetwork URLへアクセスします（必要に応じてPCのファイアウォールで許可）。

`main` にpushするとGitHub Actionsがテスト・操作確認・ビルドを実行し、成功後に自動公開します。ワークフローは `.github/workflows/pages.yml`。Viteは相対アセットパスでGitHub Pagesのプロジェクト配下に対応します。

## 拡張と資料

- `GAME_DESIGN.md`：現在のゲーム仕様
- `ARCHITECTURE.md`：独立モジュール、時間・行動・会計・保存の不変条件
- `PHASE1_DESIGN.md`：今回の設計と範囲
- `ROADMAP.md`：完成済みと次の拡張
- `AGENTS.md`：今後の開発ルール
- `TEST_PLAN.md`：検証方針

`actions.ts` のレジストリで条件・時間・費用・対象・効果を追加でき、中心の日次ループを変更せず新しい生活行動を導入できます。業種は `engine/industries/` の独立モジュールとして追加します。

## 未実装・簡略化

1都市・固定人口・安定した景況を基礎にしたモデルです。企業の基礎収入と支出、求人・人物・市場は簡略化しています。勤務曜日と開始時刻は自由に変更でき、企業別の交渉制約はまだありません。

法人設立、共同創業、従業員採用、株式・不動産売買、税・社会保険、設備売却・減価償却、NPCの独立した人生・NPC同士の交流、家族、複数都市、クラウド同期は未実装です。役割昇格はレベルとして記録し、詳細な職務権限は次の拡張対象です。

日次の計算順序は睡眠→勤務→余暇です。時間配分と実働は管理しますが、分刻みのイベント順序や現実の労働・金融制度を完全には再現していません。
