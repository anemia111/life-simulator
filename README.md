# Life Simulator v0.1

React + TypeScript + Viteで動く、日本語の人生・経済シミュレーション。PC・スマホのレスポンシブUIで、アルバイトと個人事業を両立できます。人生の目標やエンディングはありません。

## ブラウザで遊ぶ

**[Life Simulator を開く](https://anemia111.github.io/life-simulator/)**

PC・スマホのブラウザから、そのまま遊べます。インストールやログインは不要です。

セーブデータは利用中の端末・ブラウザに保存され、GitHubには送信されません。ローカル版から記録を移す場合は、ローカル版でJSONを書き出し、公開版の「セーブ・設定」から取り込んでください。

リポジトリ: [anemia111/life-simulator](https://github.com/anemia111/life-simulator)

`main` へのpush後、GitHub Actionsが計算テスト・Playwrightの主要操作テスト・本番ビルドを実行し、成功した場合だけGitHub Pagesに公開します。プルリクエストではテストとビルドのみ実行します。ワークフローは `.github/workflows/pages.yml` です。

## 起動

Windowsでは `START_GAME.cmd` を実行するとブラウザが開きます。Node.js 24以降が必要です。初回の依存関係インストールにはインターネット接続が必要です。開発サーバー起動後はゲーム内で外部APIを利用しません。

```powershell
npm ci
npm run dev
```

表示されるローカルURLを開いてください（既定は http://localhost:5173/ ）。サーバー終了はターミナルの Ctrl+C。スマホからは同一LAN上でターミナルに表示される Network URLを開きます。PCのファイアウォール設定で接続許可が必要な場合があります。セーブは端末・ブラウザ・接続先URLごとに独立します。PCとスマホの記録を移す際はJSONを利用してください。

## 遊び方

1. 名前・初期条件・保存先を選んで人生を始めます。最初に家賃を精算します。
2. 「仕事を探す」から未経験歓迎のカフェへ応募。採用は条件を満たすと確定します。
3. ダッシュボードで余暇を選び、1日・7日・30日を進めます。平日に自動勤務し、給与は毎月25日に入金します。退職時は未払給与を全額精算します。
4. スキルを学ぶと次の求人へ応募でき、事業の品質や生産能力も上がります。
5. 「事業を営む」から文章制作または焼き菓子事業を開業。余暇が事業に切り替わり、時間進行で生産・販売します。
6. 注文数と生産能力を確認し、価格調整や設備への再投資で成長させます。利益は自動的に現金へ反映され、設備投資は所持金から支払います。
7. 仕事の退職、事業の休業・再開・廃業はいつでも選べます。赤字や年齢による強制終了はありません。

## 保存

- IndexedDBの3枠。操作ごとに自動保存し、画面左下に状態を表示します。
- 起動時に保存データを選んで「つづきから」再開。
- 「セーブ・設定」で明示保存、切り替え、JSON書き出し・取り込み。
- ブラウザのサイトデータ消去でセーブが失われるため、大切な記録はJSONで保管してください。
- 不正な形式・未対応バージョンのファイルは拒否します。

## 構成

`src/engine/` に人物、時間、生活、仕事、資金、事業、所有権、都市、市場、AIの独立モジュールと日次オーケストレーターを配置。UIは `src/App.tsx`、状態接続は `src/store.ts`、IndexedDBと保存検証は `src/persistence.ts`。ゲーム計算はReactや保存処理を参照しません。金額は円の整数で、乱数による売上はありません。

`GAME_DESIGN.md` / `ARCHITECTURE.md` / `ROADMAP.md` / `AGENTS.md` / `TEST_PLAN.md` を実装前に作成し、拡張のルールと今回の範囲を定義しています。

```powershell

```

Playwrightの初回実行前に `npx playwright install chromium` を実行してください。

2026-10-20 検証：Vitest 27件、Playwright 5経路、TypeScript / Viteビルド。すべて成功。

テストは日次と早送りの一致、給与日・退職精算、月初家賃、資金不足と返済、学習と応募条件、需要・生産・原価・再投資、休廃業、寿命制限なし、保存の検証と3枠の独立性を扱います。操作テストは勤務から事業拡張、スマホ、JSON、人生切り替え、休廃業を確認します。

## 未実装・モデルの限界

法人設立、株式取引、銀行融資、不動産売買、税・社会保険、NPCの個別人生・交友、複数都市、サーバー同期は未実装です。今回のNPCは雇用主の人物データと競合の価格意思決定が中心です。

世界は1都市・固定人口・安定景況。需要は価格弾力性と品質・人口・景況・競合補正から決まる簡略モデルです。在庫・設備売却・減価償却・実際の労働制度は扱いません。設備は取得原価で評価。資金不足の生活費と固定費は無利息の未払債務になり、その後の収入で自動返済します。事業利益は税引前で開業費・設備投資を含みません。

将来の業種は `src/engine/industries/` に `IndustryDefinition` と必要に応じた独立した需要関数を配置し、レジストリに登録して追加できます。複数勤務先・複数事業への拡張には、現時点の一件制約の配列化と契約参照の更新が必要です。
